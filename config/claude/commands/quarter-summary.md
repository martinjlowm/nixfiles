Write a contribution summary of this repository for Q$1 of the current year, for the
development team.

1. Read the current date with `date` and take the year from it. Do not assume the year.
2. Collect the quarter's merged pull requests and commits with `gh` and `git log`.
3. Group the highlights under platform features, infrastructure and security, performance and
   observability, and developer experience and operations.
4. Credit each developer with what they contributed, by feature name and with numbers. Do not
   rank developers or name top contributors.
5. Write the summary to a Markdown file and print its path.
